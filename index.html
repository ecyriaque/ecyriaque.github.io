CVMI

Noter ses séries et suivre sa progression en musculation.

J’ai développé CVMI pour suivre les séances de musculation sur le web et sur mobile. L’application gère les supersets et propose des ajustements pour l’entraînement. Les deux versions partagent la même API : on peut noter ses séries hors ligne, puis les synchroniser quand le réseau revient.

  • React Native / Expo
